DBSCAN, OPTICS, and Density Connectivity

Learning goals

Distinguish core, border, and noise points; execute density expansion; choose neighborhood parameters; and explain the motivation for OPTICS and HDBSCAN.

Intuition

DBSCAN defines a group by connected dense neighborhoods instead of distance to a common center. A cluster can bend into a crescent or ring as long as a chain of sufficiently dense neighborhoods connects it. Sparse points need not be forced into a group.

It avoids specifying \(K\), but replaces that choice with a neighborhood radius and minimum local support. The number of clusters remains sensitive to those choices and to the feature representation.

Worked example

Take one-dimensional points \(\{0,0.1,0.2,0.3,0.4,2\}\) with \(\varepsilon=0.11\) and \(\mathrm{MinPts}=3\), counting each point itself. Points 0.1, 0.2, and 0.3 have three neighbors including themselves and are core points. Points 0 and 0.4 have only two neighbors but touch a core, so they are border points. Point 2 is noise.

Starting from core 0.1 absorbs 0 and 0.2. Core 0.2 expands to 0.3, which absorbs 0.4. The endpoints are 0.4 apart, greater than \(\varepsilon\), yet belong to the same cluster via a core chain. Border points join but do not expand the chain.

Theory and assumptions

Define \(N_\varepsilon(p)=\{q:d(p,q)\le\varepsilon\}\). A point is core if \(|N_\varepsilon(p)|\ge\mathrm{MinPts}\). A noncore point within a core neighborhood is border; all remaining points are noise.

To grow a cluster, inspect an unvisited point. If it is core, enqueue its neighbors and repeatedly expand core neighbors. If it is not core, mark it provisional noise; it may later be absorbed as border. Do not assume a temporary noise mark is irreversible. A border point touching two components may receive a traversal-dependent assignment, while core connectivity defines the stable dense components.

Parameters and complexity

Small \(\varepsilon\) fragments groups and increases noise; large \(\varepsilon\) merges them through bridges. Small minimum support admits accidental groups; large support suppresses small groups. A sorted neighbor-distance plot can suggest a radius, but ensure its neighbor count matches whether self is included.

Spatial indexes can make low-dimensional sparse-neighborhood queries approximately \(O(n\log n)\) overall in favorable cases. Brute-force distance work is \(O(n^2d)\); dense neighborhoods or high dimensions can make time quadratic and implementations storing all neighborhoods can also require quadratic memory. It is therefore inaccurate to state either that DBSCAN is always quadratic or always \(n\log n\).

OPTICS

OPTICS creates an ordering with reachability information that exposes cluster structure across a range of density levels. The core distance of a point is the radius needed to include the specified minimum number of neighbors. Reachability from core point \(o\) to \(p\) is

\[\operatorname{reachability}(p\mid o)=\max\{\operatorname{core\_distance}(o),d(o,p)\}.\]

Valleys in a reachability plot suggest dense groups separated by higher-distance transitions. A later extraction rule selects clusters from this ordering. OPTICS is not simply DBSCAN magically finding a perfect separate epsilon for each point: it still needs support, distance, and extraction choices.

HDBSCAN

HDBSCAN constructs a hierarchy using density-related connectivity, typically through mutual-reachability distances and a spanning-tree structure, then selects stable groups from a condensed hierarchy. Minimum cluster size and support influence the result. It is useful to consider when densities vary, but does not guarantee meaningful clusters in arbitrary high-dimensional noise.

The clustering reference discusses DBSCAN, OPTICS, HDBSCAN, and implementation-specific scalability. Choose and measure the actual implementation rather than transferring a complexity claim across algorithms.

Practice and pitfalls

Scale or weight features so neighborhoods reflect meaningful similarity. In high dimensions, distances can concentrate and local-density distinctions weaken. A single global radius can merge a sparse group while preserving a dense one, or preserve the sparse group only by merging dense neighbors.

Method Group definition Main output
K-means Nearest mean under squared distance Hard assignment, specified K
GMM Posterior Gaussian component Soft membership, specified K
DBSCAN Connected core neighborhoods Cluster labels plus noise
OPTICS Reachability ordering across density levels Ordering and extracted labels
HDBSCAN Stable groups in a density hierarchy Selected groups plus noise

Noise labels mean sparse under the chosen representation, not necessarily fraud, error, or an undesirable observation. Compare stability across nearby parameter choices and inspect why each cluster matters to the task.

Interview questions

Can border points connect two DBSCAN clusters? They cannot expand a cluster; connectivity must pass through core points.

Why can DBSCAN recover moons? It follows locally dense chains rather than requiring one convex nearest-center region.

Does no predefined K mean no tuning? No. Radius, support, metric, and representation determine the answer.

Summary

Density methods make connected local support the grouping criterion. Their flexibility with shape comes with sensitivity to scale, density variation, and neighbor computation.
