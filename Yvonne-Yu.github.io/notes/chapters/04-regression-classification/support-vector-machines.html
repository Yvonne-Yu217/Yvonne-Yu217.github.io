Support Vector Machines: Margins and Hinge Loss

Learning goals

Explain geometric margins, derive hinge loss from slack constraints, and distinguish a linear soft-margin classifier from a nonlinear kernel model.

Intuition

Many hyperplanes may separate two classes. A support vector machine chooses a separator with a large clearance from training observations. The points constraining that clearance are support vectors; moving a distant non-support point slightly need not change the boundary.

Use labels \(y_i\in\{-1,+1\}\) and one consistent score convention, \(f(x)=w^\top x+b\). The decision boundary is \(f(x)=0\). Rescaling \((w,b)\) leaves the boundary unchanged, so impose functional-margin constraints to define its scale.

Worked example

In one dimension, negative examples are \(x=-2,-1\) and positive examples are \(x=1,2\). Set \(w=1,b=0\). Then every \(y_if(x_i)\ge1\), and the support vectors lie at \(-1\) and \(1\). The geometric margin between supporting planes is \(2/\|w\|=2\).

For a positive example at \(x=0.2\) under the same score, \(y_if(x_i)=0.2\) and hinge loss is \(0.8\). It is correctly classified but inside the margin. A positive example at \(x=-0.2\) has hinge loss \(1.2\) and is misclassified. Slack is therefore a measure of margin violation, not only a count of wrong labels.

Theory and assumptions

The hard-margin optimization is

\[\min_{w,b}\frac12\|w\|^2\quad\text{subject to }y_i(w^\top x_i+b)\ge1.\]

The two supporting planes have scores \(+1\) and \(-1\), hence their separation is \(2/\|w\|\). Hard-margin feasibility requires linearly separable data and is brittle to outliers.

Soft margin introduces \(\xi_i\ge0\):

\[\min_{w,b,\xi}\frac12\|w\|^2+C\sum_i\xi_i, \qquad y_if(x_i)\ge1-\xi_i.\]

For a fixed score, the smallest feasible slack is \(\xi_i=\max(0,1-y_if(x_i))\). Substitution yields regularized hinge-loss minimization. An equivalent convention uses \(\lambda\|w\|^2+n^{-1}\sum_i\xi_i\); larger \(C\) emphasizes training violations while larger \(\lambda\) emphasizes regularization.

A soft margin permits violations but does not by itself make the boundary nonlinear. Kernel methods replace dot products by \(K(x,z)=\langle\phi(x),\phi(z)\rangle\), implicitly fitting a linear separator in a transformed feature space. An RBF kernel uses \(\exp(-\gamma\|x-z\|^2)\); its length scale controls how local the boundary can become.

Practice and pitfalls

Scale distance-sensitive features using training-fold statistics. Tune regularization and kernel parameters within cross-validation; large RBF \(\gamma\) can create very local, overfit boundaries. Kernel methods may be expensive for large sample sizes, while linear solvers are useful for high-dimensional sparse representations.

The decision score is not automatically a calibrated probability. If probabilities are required, fit and validate calibration without using the final test labels. Class weights change the optimization cost of errors and should reflect the objective, not be treated as an automatic cure for imbalance.

Interview questions

Can a correctly classified point have nonzero hinge loss? Yes, if its functional margin is between zero and one.

What does increasing \(C\) do? It makes margin violations more expensive relative to the weight norm; the model may accept a narrower margin to fit training data.

How does SVM differ from logistic regression? Both can fit a linear decision boundary, but hinge loss emphasizes margin violations while log-loss estimates conditional class probabilities under its model.

Summary

Hard margin maximizes separation under feasibility. Soft margin trades that separation against hinge penalties. Kernels introduce nonlinear geometry; they are a separate choice from allowing slack.
