Seeing Sentiment: News Images, Retail Participation, and Chinese A-Share Index Returns

Xiaobin Liu, Kaixin Wang, Yi Yu, Tao Zeng (作者按姓氏字母顺序排列) Yi Yu 是我的法定姓名。

共同作者 · 工作论文 2024年11月 — 至今

本研究考察财经新闻图像中的情绪是否包含文本之外的收益预测信息。基于2014—2026年24.5万篇文章和57.2万张图片，构建日频图文情绪指标，通过联合回归和文本正交化比较五个A股指数。图像信号主要集中在高波动期的创业板，与散户参与程度呈描述性对应。扩展窗口预测显示小幅且随时间变化的改善。合并跨指数推断仅达到10%水平，创业板样本外结果未通过五指数5%水平的校正。

研究问题

新闻图片能否提供文本之外的预测信息？

从同一新闻语料构建图像与文本情绪指标，再检验它们与收益的关联集中于哪些市场和波动状态。

核心比较是图像相对文本的增量信息，以及这种关系在波动状态和指数之间的差异。

主要结果

图像与收益的关联集中于高波动期创业板

在五个指数间，对照系数排序与换手率、流通市值倒数和散户账户占比。

各散户代理指标的秩相关均为0.80，五个指数呈现与散户参与程度相符的描述性排序。

研究结论

多模态情绪预测存在状态与市场边界

主要发现是预测关系集中于高波动、散户参与较高的市场；合并推断提供提示性证据，整体强度仍有限。

论文的贡献在于定位多模态情绪何时、何处包含收益预测信息，并界定这一证据的推广范围。
