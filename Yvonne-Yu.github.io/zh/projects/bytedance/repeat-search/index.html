方法

明确用户粒度与时间窗口

用 DML-SparseLinear 调整已记录的历史差异，研究触点与后续复搜。

触点累计至首次复搜，导致窗口长短不同，可能使估计产生偏差。

模型

先调整历史差异，再估计效应

DML 先剥离历史行为可解释的部分，再分析触点与结果的剩余关系。

调整历史变量无法消除未观测混杂，也不能修复结果依赖的触点窗口。

解释

将信号转为待验证的策略

区分观察性信号与反转实验证据。

这些结论用于提出策略假设，不能仅凭该 DML 设计认定因果效应。
