科研经历 /小语言模型协作研究

Three Heads Are Better Than One, If They Share Notes: When and How LLM Teaming Helps Short-horizon Reasoning Tasks

Caijun Wang, Yishu Yang, Yvonne Yu

研究合作者 2026年2月 — 2026年5月

本研究考察异构语言模型在推理任务中何时适合协作，以及应在哪个环节协作。短上下文基准上的投票、辩论和裁判方法均弱于单模型直接回答。转向 ConTRoL 长篇章任务后，我们让模型共同检索和核验证据，再由单个模型回答。固定 Qwen3-8B 后，包含直接回答回退的 F1 完整流程准确率为71.7%，单模型检索基线为65.5%。字符级审计检查原文支持，接受率与回退率刻画证据筛选行为；结论限于已评估的任务和模型配置。

证据协作架构

共享证据先核验，再由单个模型回答

核验实验改用 Qwen3-8B 回答；模型共同检索和检查证据，再选择一条回答路径。

保留证据作答与直接回答回退互斥，两条路径都保留原始输入，并使用同一个回答模型。

主要对照结果

完整 F1 流程提高6.2个百分点

固定 Qwen3-8B 为回答模型时，F1 准确率为71.7%，单模型检索基线为65.5%。

提升对应包含回退的完整 F1 与 RQA 的比较，不能单独归因于核验模块。

研究结论

让协作方式与任务结构相匹配

实验区分答案聚合、证据汇集和证据核验；结果来自不同任务与模型配置，需分别解释。

结果支持进一步研究证据环节的协作；跨任务推广与部署效率仍待验证。
