证据协作架构

汇集并核验证据，再选择一条回答路径

从短上下文答案聚合，转向 ConTRoL 长篇章的证据选择；主要核验比较固定 Qwen3-8B 为回答模型。

每道题只走一条分支，两条路径使用同一个回答模型。

证据核验方法

比较由谁核验同一批候选证据

F1 与 F2 保持检索、提示词和回答模型一致。

单纯汇集与加入核验是不同方法，结果需分别比较。

动手理解方法

沿着证据，一步一步理解。

示意数据 · 不代表实际业务或研究结果

“图书馆在工作日六点关门，周六四点关门，周日闭馆。”
问题：周六五点能进入图书馆吗？

从前提中检索周六的句子。工作日的句子看似相关，但不适用于这个问题。

预设的教学示例，不运行在线模型，也不生成基准测试结果。

预设示例：检索“周六四点关门”，对照原文核实依据，再回答五点已超过开放时间。没有证据通过时，同一回答模型使用仍包含关门时间的原始输入。该示例解释流程，不代表基准测试效果。
