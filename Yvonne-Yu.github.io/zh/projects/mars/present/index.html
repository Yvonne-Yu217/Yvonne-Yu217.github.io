检测方法

不同检测方法覆盖不同闲置模式

先合并候选标记，再进入监督排序。

保留缺失信息，监控缺失不等于零利用率。

训练与验证

围绕固定审核预算，为候选排序。

SHAP 解释单个资源的得分，不代表因果关系。

云资源排序 · 监督排序与评估 2 / 2

人工回验

前 100 项人工回验命中率约 85%

运维检查候选是否满足释放或降配条件。

这是特定队列的 Precision@100，不能外推为全部云资源的准确率。

云资源排序 · 生产部署与监控 2 / 2

生产监控

Power BI 区分漂移信号与审核表现

分别监控数据健康、模型行为与运维工作量。

PSI 用于触发排查；审核命中率需等待审核结果确认。

云资源排序 · 概率校准与发布治理 1 / 1

校准与治理

从校准概率到可申诉的治理建议

在更晚的留出集上检查可靠性与 Brier 分数。

执行动作由运维批准，模型不自动释放资源。

云资源排序 · 反馈与成本核验 1 / 2

结果反馈

审核结果回流标签，执行动作单独核验

按业务含义结构化 ServiceNow 处理结果。

未响应仍属未确定状态，不直接作为训练标签。

云资源排序 · 反馈与成本核验 2 / 2

流程结果

单次排查由 52 分钟降至 31 分钟

预填利用率证据与建议动作，减少重复排查。

比较对象是排查流程耗时，不是模型运行时间。
