E-commerce search · Repeat-Search Causal Analysis 1 / 3

Method

Define the user and time windows

DML-SparseLinear adjusts for recorded history when studying touchpoints and later repeat search.

Accumulating exposure until the outcome creates unequal windows and can bias estimates.

E-commerce search · Repeat-Search Causal Analysis 2 / 3

Model

Adjust for history before estimating effects

DML separates historical predictability from the remaining exposure–outcome relationship.

Adjustment cannot resolve unmeasured confounding or outcome-dependent exposure windows.

E-commerce search · Repeat-Search Causal Analysis 3 / 3

Interpretation

Translate signals into testable strategies

Observational signals and reversal-experiment evidence play different roles.

These are strategy hypotheses; the DML design alone does not establish causal effects.
