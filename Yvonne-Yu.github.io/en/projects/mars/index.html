Mars · Idle cloud resource detection and ranking

Data Scientist Intern May–Aug 2025

Built a two-stage resource ranking pipeline with Azure ML scoring and operations feedback.

Project work

  1. 01

    Feature & Candidate Pipeline

    Built incremental resource-by-day ETL and 7/30/90-day features; combined three detection paths into a daily candidate pool.

    Present · 2 slides →
  2. 02

    Supervised Ranking & Evaluation

    Trained XGBoost on operations labels with time splits and class weights; manual Precision@100 reached approximately 85%, with SHAP reason codes.

    Present · 2 slides →

    Present · 2 slides →
  4. 04

    Calibration & Governance

    Calibrated idle probabilities with Isotonic Regression, set Top-K to operations capacity, and gave tagged candidates a 14-day appeal window before ticketing.
